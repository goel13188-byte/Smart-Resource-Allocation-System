IMPORT SAFETY
-------------
Run npm run seed:dataset only against a fresh, empty application database. The importer checks for existing organizations and stops if any are present; it does not reset or overwrite an existing dataset. Starting the server creates missing schema/reference tables but does not import these sample organizations.

Commands from the project root:
  npm install
  npm start
  npm run seed:dataset

After import, start the server and open:
  http://localhost:5001

The application needs valid local MySQL credentials in .env. The importer and login cannot be verified until the MySQL service accepts those credentials.
